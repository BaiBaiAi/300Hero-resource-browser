# 300英雄资源浏览器

> **非官方第三方本地资源浏览工具。本项目不包含或分发任何游戏资源，仅读取用户本机已有文件；相关游戏资源及知识产权归其合法权利人所有。**

独立的 Python 本地服务和网页资源浏览器，用于读取 300英雄游戏目录中的全部 `Data*.jmp`，进行跨包搜索、角色关联搜索和本地预览。

## 功能

- 扫描所有 `Data*.jmp`，并在一个索引中全包搜索；
- 对完整索引和抽样内容验证通过的非标准包头资源包开放预览；
- 按全部、模型、Live2D、贴图、技能特效、语音/音效、配置/其他分类筛选；
- 输入英雄编号进行关联搜索，例如 `121` 会汇总路径中归属于该角色的模型、皮肤、贴图、技能特效和音频；
- 图片直接显示，支持方向移动、滚轮缩放和复位；
- jumpX 与 EG3D 模型使用 WebGL 显示材质贴图和真实三角网格，支持鼠标拖动、缩放、平移及原始骨骼动作；
- Cubism 2 Live2D 使用内置的 PixiJS 社区网页运行时加载完整模型族、纹理和 MTN 动作；
- 浏览器支持的音频直接播放，FMOD BANK/FSB 可选择并解码播放单条音轨；
- DAT 表格显示列和记录；
- UI、XMAP、MAP、字体、文本及未知二进制显示可识别内容和结构化报告；
- FMOD BANK/FSB 显示音频块和音轨信息；
- 仅提供本地检索与预览，不提供资源导出、游戏文件修改、注入、替换、导入或 JMP 回写功能；
- 不包含 Lua 资源库、Lua 文档或 Lua 接口知识库。

## 运行

```powershell
python -m pip install -r requirements.txt
python app.py
```

需要 Python 3.10 或更高版本；也可以双击 `start_browser.bat` 启动。程序固定监听：

```text
http://127.0.0.1:9961/
```

首次启动时如果没有找到 JMP，会弹出文件夹选择窗口。成功选择后，路径记录在 `config/settings.json`。

FMOD BANK/FSB 音轨播放使用项目内附带的 vgmstream 解码器，其许可与来源说明位于 `tools/vgmstream/`。

## 项目结构

```text
app.py                 HTTP 服务和资源 API
jmp_core.py            JMP 解析和资源读取
catalog.py             全包目录、分类和角色归属分析
resource_inspector.py  文本与二进制格式报告
dat_table_backend.py   DAT 表格解析
audio_backend.py       FMOD BANK/FSB 信息解析
settings_store.py      游戏目录配置
web/                   网页界面和离线 WebGL 模型运行时
web/live2d_viewer/     Cubism 2 网页查看器及许可证
tools/vgmstream/       FMOD 音轨解码器及许可证
```
